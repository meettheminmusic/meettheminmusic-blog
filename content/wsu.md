## Teaching materials

### [Marching Band Docs](https://apps.apple.com/us/app/marching-band-docs/id6794717287)

iOS app on the Apple App Store (2026). Rehearsal management tool for marching band directors and drill instructors; syncs show notation with drill charts.

### [Rhythm Builder](/rhythm-builder/)

Web tool (2026). Browser-based rhythm notation generator built on ABC notation, with tie handling, lyric entry, and automatic syllabification.

### [Visual Schedule Builder](/visual-schedule-builder/)

Web tool (2026). Builds visual lesson schedules where each activity gets a picture, notes, and an optional link or media popup, then exports a standalone file for classroom display.
